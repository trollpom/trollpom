# Евгений Смирнов

**Продакт-менеджер медицинского оборудования · прикладной ИИ · автоматизация**

Работаю с лабораторным оборудованием для ИФА и ИХЛА. Изучаю потребности пользователей, формулирую требования, сравниваю продукты и веду проекты. В собственных приложениях исследую, как ИИ помогает планировать работу и решать повседневные задачи.

Разрабатываю с помощью ИИ и AI coding tools: определяю задачу и сценарии, направляю реализацию, проверяю результат и ограничения. Развиваю навыки Python, JavaScript и TypeScript. Моя профессиональная основа — управление продуктом; эти проекты показывают практику создания прототипов, а не заявленный опыт промышленной разработки.

## Моя роль в команде

- Разобрать потребность и сформулировать проверяемую задачу.
- Выбрать сценарий прототипа, приоритеты и ограничения.
- Собрать интерфейс и интеграции с помощью AI coding tools.
- Проверить результат и объяснить, где нужны дополнительные данные или ручная проверка.
- Подготовить демонстрацию и презентацию решения.

Интересы: автоматизация работы с почтой и документами, инструменты принятия решений, B2B и лабораторная диагностика.
